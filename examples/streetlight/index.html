    Streetlights Kafka API¶

    Example rendering of Streetlights AsyncAPI example from asyncapi.com.

    Version: 1.0.0

    Specification: asyncapi 3.0.0

    Attachment Description
    Specification Source AsyncAPI specification in json format
    Sample messages Example payloads for each message type

    License: Apache 2.0

    The Smartylighting Streetlights API allows you to remotely manage the city lights.

    Check out its awesome features:¶
    • Turn a specific streetlight on/off 🌃
    • Dim a specific streetlight 😎
    • Receive real-time information about environmental lighting conditions 📈

    Default content type: application/json

    Servers¶

    scram-connections¶

    kafka-secure://test.mykafkacluster.org:18092

    Test broker secured with scramSha256

    env:test-scram kind:remote visibility:private

    Security: saslScram

    Type: scramSha256

    Provide your username and password for SASL/SCRAM authentication

    mtls-connections¶

    kafka-secure://test.mykafkacluster.org:28092

    Test broker secured with X509

    env:test-mtls kind:remote visibility:private

    Security: certs

    Type: X509

    Download the certificate files from service provider
